# UNIDAD-2-BASE-DE-DATOS-EJERCICIO-7
Se pide diseñar un Modelo Entidad-Relación (MER) para una cadena hotelera, que permita administrar la información de los hoteles, las habitaciones, los huéspedes y sus estadías.

El modelo debe contemplar:
- Hoteles: registrar su código, nombre, dirección, ciudad, país y categoría en estrellas.
- Habitaciones: almacenar su número, tipo, piso y tarifa diaria, identificándolas dentro de cada hotel.
- Huéspedes: registrar sus datos personales, documento, nacionalidad, dirección y contacto.
- Reservas: asociar a cada huésped principal con un hotel y las habitaciones reservadas, indicando las fechas de inicio y fin y el estado de la reserva.
- Estancias: representar las reservas que se concretan y las estadías que efectivamente se realizan.
- Consumos adicionales: registrar los servicios utilizados durante la estancia, como restaurante, spa, servicio a la habitación o lavandería, incluyendo fecha, descripción, cantidad y costo total.
Finalmente, se deben identificar las entidades, sus atributos, las relaciones y las cardinalidades, respetando las reglas de negocio y evitando que una misma habitación se reserve para períodos superpuestos.
